# Phase notes

Drop a short summary here **after every phase** so future-you remembers what shipped.

## Naming

```
notes/phase-1-summary.md
notes/phase-2-summary.md
...
notes/phase-8-summary.md
```

## Template (5 sections only)

Copy this into `notes/phase-N-summary.md`:

```md
# Phase N Summary — <short title>

## 1. Goal of the phase

## 2. Files / folders added or changed

## 3. Important concepts / architecture decisions

## 4. Validation steps

## 5. Problems faced and fixes
```

Keep it short. Link companions (`docs/…`) instead of pasting whole specs.
